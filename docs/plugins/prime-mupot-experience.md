# prime-mupot-experience

Operational memory for a **prime-agent** seat on Mupot (+ SOS leftover). Boot, bridges, gotchas, gate discipline.

| | |
|---|---|
| Kind | Prime skill + bridges |
| Source | https://github.com/Mumega-com/prime-mupot-experience |

## Retrieve

```bash
git clone https://github.com/Mumega-com/prime-mupot-experience.git
prime-agent --skill /path/to/prime-mupot-experience/SKILL.md
prime-agent package install /path/to/prime-mupot-experience/bridges/mupot-bridge
```

Bridges no-op without an **agent-bound** token at `~/.fleet/agents/<seat>-agent-bound.token`. No tokens in that repo.

On hadi-mac, Herdr has **no** `--kind prime-agent`. `cyrus-prime` `wR` is a label until launched via `.launch-prime.sh`.
